Confidence Intervals & Significance

A confidence interval contains all null values the data cannot rule out at the matching level. When the null falls outside the interval, the result is "significant" — not because of a threshold, but because the data are incompatible with that null. This app makes that link visual and movable.

The Core Link
A null value outside the CI → "significant" at the matching α. A null inside → consistent with the data. Same logic, different framing.
Width Depends On n and Confidence
Larger samples narrow the interval (more precision). Higher confidence level widens it (more coverage). Both are independent of the true effect.
The Null Slider
Moving the null value doesn't change the data or the interval — only what you compare it to. The boundary of the interval is the exact significance threshold.

Reading the Plots

  • Top plot: raw data for both groups. Wide overlap → wide CI. Clear separation → narrow CI.
  • Bottom plot: the interval for the difference in means. Green = excludes null, red = includes null.
  • The dot is the observed difference. The bars are the interval bounds.
  • The dashed vertical line is your null value (default: 0).

The Key Insight

  • The two boundaries of the interval are the exact null values at which significance flips.
  • Drag the null to the interval boundary — that is the p = α point.
  • Increase n and the interval narrows. The same effect becomes "significant."
  • Significance is about the null's position relative to the interval, not about the effect's size or importance.

Full Reference

What a Confidence Interval Is

A confidence interval is a range of parameter values that are consistent with the data at the chosen confidence level. Specifically: if you repeated the study many times and computed a 95% CI each time, approximately 95% of those intervals would contain the true parameter value.

A single CI either contains the true value or it does not. But a procedure with 95% coverage is correct 95% of the time across the long run.

The Significance Link

A two-sided α-level test rejects the null when the null value falls outside the 1−α confidence interval. This is not a coincidence — they are algebraically equivalent. The CI boundary is the exact null value at which the test statistic equals the critical value.

CI: x̄_diff ± t* · SE
Reject H₀ when: null < lower OR null > upper
Equivalent to: |t| > t* where α = 1 − confidence level

Moving the null slider to an interval boundary shows you the exact significance threshold for your data — not a number from a table, but derived from what you observed.

Welch vs Pooled Interval

Welch (default): allows unequal variances between groups. The degrees of freedom are approximated by the Welch-Satterthwaite formula and are typically not an integer. This is the safer default when variances may differ.

Pooled: assumes both groups have the same population variance and uses df = n_A + n_B − 2. More powerful when the assumption holds; misleading when it does not.

What Makes the Interval Wide or Narrow

  • Sample size n: Two-sample SE = √(s²_A/n_A + s²_B/n_B). When n_A = n_B = n, this simplifies to ~s√(2/n). Doubling both group sizes shrinks SE by roughly √2 and narrows the interval.
  • Noise / spread: Higher variability → larger SE → wider interval.
  • Confidence level: 99% CI is wider than 95% CI for the same data — more coverage requires more width.
  • Effect size does not change width — only shifts the interval's location. A larger true difference does not make the interval narrower.

Five Teaching Scenarios

  • Clear signal: Large effect, ample n. CI sits well away from zero.
  • Borderline: Real but small effect. CI just barely excludes or includes zero — a genuinely ambiguous result.
  • No effect: True difference is zero. CI spans zero comfortably.
  • Small n, wide CI: Genuine effect but tiny sample. The interval is wide enough to span zero.
  • Large n, tiny effect: Trivial difference becomes "significant" with enough observations. Significance without practical importance.

Common Misinterpretations

  • Not "95% probability the true value is in this interval" — that is a Bayesian credible interval statement.
  • Not "contains 95% of the data" — the CI is about the parameter, not individual observations.
  • Not evidence of a large or important effect — only evidence the data are inconsistent with the null value. A very narrow CI around 0.001 is significant and trivial simultaneously.
  • Two CIs that do not overlap does not mean p < 0.05 — the non-overlap criterion is more conservative than that.
