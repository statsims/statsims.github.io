ABOUT AMBERDOS
AmberDOS Text Editor v1.9 A single-file retro CRT-style plain-text editor with DOS-inspired visuals. Main features: - plain ASCII text editing - ASCII character map and window builder - find, replace, and line navigation - Amber Phosphor, Green Phosphor, and White Phosphor themes - browser voice output with a WOPR-inspired preset - calculator mode with notebook-style outputs and persistent variables
